# 全球近现代设计美学与文字叙事风格总控套件 (`ai-style-design`)

> 本套件为反重力 (Antigravity) 平台上的高级设计美学与抗 AI 同质化工程中枢。它打通了世界 20 大视觉流派与 16 大传世叙事修辞，提供从**「风格与同质化诊断」**到**「智能设计与工业级 Prompt 调度」**的全链路能力。

### 1. 风格分析与 5 维同质化诊断：`style-analyzer`
- **使用时机**：当用户给出一段视觉提示词（Midjourney/SDXL Prompt）、文案草稿、排版草案，想要知道其属于何种历史流派、是否存在 AI 塑料感/泛滥蓝紫霓虹/公关套话，并需要向纯正流派重构时使用。
- **详尽规范**：[阅读 `style-analyzer` 接口文档](./skills/interfaces/style-analyzer/SKILL.md)
- **CLI 快速调用**：
  ```bash
  python scripts/style_analyzer.py --input "你的设计描述或Midjourney提示词"
  ```

### 2. 智能设计与生成调度接口：`style-designer`
- **使用时机**：当用户需要为特定产品、包装、品牌海报、终端 UI 制定整体设计方案，或者要求严格按照某个流派（如包豪斯、新中式、粗野主义）生成设计系统时使用。
- **详尽规范**：[阅读 `style-designer` 接口文档](./skills/interfaces/style-designer/SKILL.md)
- **CLI 快速调用**：
  ```bash
  # 模式 A：自主情境识别与推荐
  python scripts/style_designer.py --query "高端高山冷萃乌龙茶包装"

  # 模式 B：严格锁定包豪斯
  python scripts/style_designer.py --query "模块化机械键盘" --mode strict --visual style-bauhaus

  # 模式 C：先锋实验融合
  python scripts/style_designer.py --query "先锋电子音乐节" --mode hybrid
  ```

## 🧠 高阶抗 AI 同质化核心宪章 (Anti-AI Cliché & Authenticity Codex)

> **⚠️ 核心警示**：现代读者的“审美抗体”已经全面进化。过去 AI 味是“塑料感、病句、无脑蓝紫”；**当下的 AI 味，恰恰是“过度工整、句句闭环、每一步都在预设之内”的高级样板戏**。本套件在根目录下设立以下两大核心审计法则，所有子接口、文案生成与风格纯化必须严格遵行：

### 1. 警惕“吃了不烧心”式的样板戏民间哲人 (Craftsman Archetype Trap)
- **病征解剖**：
  - 现象：在描写任何手艺人、摊主、工人、硬汉时，AI 天然倾向于生成短视频或公众号特稿式的假人——*“从盒里抽出一根烟，没点，咬在嘴里”*、*“眼皮都没抬一下”*、*“冷冷道出一句看透行业与世事的土味哲理（如‘先把规矩立住’、‘一天差个十秒八秒是它的本分’）”*、*“顾客心领神会默默受教”*。
  - 本质：这与短视频里顾客说“老板你家贵是贵了点但吃了不烧心”、摊主回应“宁可少挣点也不能坏了规矩”如出一辙，是用预设好的剧本完成一次**廉价的道德与认知爽感交付**。
- **纯化律令**：
  - **剥离刻奇高人，回归世俗毛刺**：真正的劳动者是算账的、疲倦的、烦躁的、带着生计磨损的。写手艺人必须允许“嫌麻烦、讲价钱、粗俗、无效碎嘴、甚至无动于衷”，坚决斩断对答如流的戏剧性顿悟闭环。

### 2. 文学讽刺与叙事创作的 5 大高级机械病征 (The 5 Mechanical Traps of AI Satire)
在进行世界观构建、讽刺写作与黑色幽默生成时，严禁触犯以下 5 大典型 AI 病征：

| 病征序号 | 机械通病特征 (Anti-Pattern) | 典型 AI 翻车表现 | 真实人类文学法度 (Authentic Protocol) |
| :--- | :--- | :--- | :--- |
| **TRAP-01** | **潜台词明态化 (Over-explaining)**<br>破坏死鱼眼冷面笑匠法则 (Deadpan Inversion) | 生怕读者看不懂讽刺，在公文中直接写出“致全体耗材”、“期待你的下一具遗体”。把讽刺打在公屏上，变成浅薄的恶毒。 | **死鱼眼式的无辜**。越是残酷荒谬，官方口吻越要正经体面、神圣纯洁。讽刺的闭环必须由读者在脑中自行完成。 |
| **TRAP-02** | **世界观专有名词硬塞 (Buzzword Stacking)**<br>设定过载挤死留白 | 每一句话都要塞入“管理式民主”、“战术上行链路”、“真理部速记员”，生怕别人不知道在写什么设定，字里行间透着油腻自嗨。 | **平实质朴的日常白描**。用最普通的字眼（如“空气带着松香味”、“击杀指定数量”）写最反常的事，留足心理呼吸感。 |
| **TRAP-03** | **脸谱化恶人取代体制冷漠 (Caricature vs Indifference)**<br>小丑反派化取代平庸之恶 | 把国家机器写成咬牙切齿、刁难讥诮的卡通大恶霸（如“赶紧去下一颗废料星球”）。 | **程序正义的冷酷与不在乎**。体制根本不在意个体的死活，只在乎报表、流程与配额，甚至真诚地认为给予了你至高荣誉。 |
| **TRAP-04** | **粗暴抹杀活人体温与社群默契 (De-humanization of Subtext)**<br>把战友温情降维成机械代码 | 将玩家/民间自发形成的戏谑暗号（如将掉线称为“熊科物种伤人”、社区放假）粗暴抹平为“肃清叛国”，杀死人类的幽默与温情。 | **尊重人类在苦难与荒谬中的默契**。保留人与人之间心照不宣的微小体温与战友同袍式的调侃。 |
| **TRAP-05** | **格式化三段式与金句强迫症 (Punchline Slogan Cliché)**<br>结构僵化与二律背反预制菜 | 必然遵循：`大词铺垫 -> 反差铺陈 -> 尾段二律背反金句收尾`。每一步都在读者的算力预期之内。 | **打破预期，允许未完成态**。结尾可以停在一个具体的无意义动作、一声咳嗽、或者一段未干的水渍上，不强行升华。 |
