# 接口规范：反重力智能设计与生成调度接口 (`style-designer`)

> 本接口为 AI 设计美学知识体系的最高级调度引擎，扮演**“AI 首席创意总监 (Chief Creative Director)”**角色。直通底层 36 大流派语料库与集中特征索引矩阵 [`corpus_index.json`](file:///f:/ai风格设计/corpus_index.json)，向终端用户与 Agent 提供确定性、工程化、抗同质化的专业设计方案交付包。

## 1. 接口定位与架构拓扑 (Mission & Architecture)

传统大模型辅助设计最大的痛点在于**输出随机、风格漂移、审美泛化**。

`style-designer` 接口通过工程化手段，将全球近现代传世设计流派的**视觉 DNA 与文字声音**严密打包，提供双轨调度能力：
- 当用户没有明确风格概念时，通过情境语义推理，**自主推荐最契合的视听组合**；
- 当用户明确指定流派时，**彻底锁死纯正血统参数**，实施绝对负向过滤，绝不掺杂平庸的通用 AI 废料。

## 2. 双核心调度模式详析 (Dual Operating Modes)

### 2.1 模式 A：自主情境识别与协同推荐 (Scenario Affinity & Hybrid Mode)
- **触发条件**：用户输入模糊设计需求（如“为独立咖啡馆设计海报”、“高端智能电车座舱 UI”、“先锋艺术节主视觉”），未强制指定具体设计流派。
- **运作机理**：
  1. **场景语义意图识别**：遍历预设的情境亲和度映射表（Scenario Affinity Matrix），分析产品定位、受众人群与情绪基调；
  2. **黄金声色协同匹配**：从 36 大库中抽取最佳的「视觉流派 + 叙事修辞」搭配（如当代文人写意 + 新东方风土嗅觉体；包豪斯 + 乔布斯激进清澈体；瑞士国际主义 + 奥格威事实密集流）；
  3. **先锋跨界对撞支持 (可选)**：用户开启 `--experimental` 或指定融合时，调度两组高反差流派（如瑞士网格 × 热带粉蓝；粗野混凝土 × 装饰艺术金）实现前卫破局。

### 2.2 模式 B：严格正统限定锁定 (Strict Pureblood Mode - 100% Purity)
- **触发条件**：用户明确指定了流派名称或 ID（如“使用包豪斯风格设计”、“严格遵循拉美热带现代主义”、“用鲁迅匕首体写文案”）。
- **运作机理**：
  1. **参数绝对锁定**：从 `corpus_index.json` 中完整提取该流派的特调色盘（60:30:10 阶梯）、物理微观肌理与网格度规；
  2. **开启硬性负向过滤**：强制将该流派专属的禁忌词库与全局反同质化词库（塑料高光、无脑渐变、大头居中等）注入生成引擎；
  3. **输出 100% 纯正交付物**：杜绝任何现代廉价元素的渗入，保证流派血统的绝对纯净。

## 4. 自动化调用与 CLI 快速指引

本接口配备全自动 Python 引擎 `scripts/style_designer.py`，支持无依赖直接运行：

```bash
# 模式 A：自主情境识别与推荐（输入业务主题即可）
python scripts/style_designer.py --query "高端高山冷萃乌龙茶包装"

# 模式 B：严格正统单流派锁定（指定流派 ID）
python scripts/style_designer.py --query "模块化机械键盘海报" --mode strict --visual style-bauhaus

# 模式 C：跨流派先锋实验融合对撞
python scripts/style_designer.py --query "先锋电子音乐节" --mode hybrid

# 输出原始 JSON 供程序化接口集成
python scripts/style_designer.py --query "..." --json
```

## 6. 与 `style-analyzer` 闭环协作

1. **协同工作流**：
   - 企划启动阶段：使用 `style-designer` 制定全套视觉与文字资产规范；
   - 产出审查阶段：将生成的图像提示词或撰写的文案输入 `style-analyzer` 进行同质化审计打分；
   - 持续纯化迭代：根据诊断扣分项针对性修复，直至「同质化指数 ≤ 15%」，实现真正的文化纯血正统设计。
