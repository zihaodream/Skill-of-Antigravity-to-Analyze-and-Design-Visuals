# Codex适配说明

## 保留内容

20份视觉和16份叙事原典逐字节复制为 `references/visual/*.md` 与 `references/narrative/*.md`。原版七项诊断的关键词、单次扣分和维度上限提取为JSON数据，未改写词表。

## 适配内容

| 原版 | Codex版 |
| --- | --- |
| 总入口和两个平台接口、接口副本 | 一个 `ai-style-design` 入口与两份按需读取的流程 |
| 原典都是可发现的SKILL.md | 原典作为普通参考Markdown，避免38个技能同时参与发现 |
| 接口引用源机器 `file:///` 路径 | 入口和流程全部使用包内相对引用 |
| 38条索引含接口指令 | Codex索引仅含20视觉+16叙事，平台接口由新流程承接 |
| 标题五维、实际七项 | 明确七项；CLI按140分上限归一化到0–100 |
| 匹配度／100%纯度表述 | 流派把握度和设计约束，不声称经校准概率或历史真实性保证 |
| 默认旧版Midjourney旗标 | 通用提示词为主，指定平台后再确认平台语法 |
| 固定网格、留白与配色规则 | 按流派、媒介和品牌约束选择参数 |
| 原版构建和Gemini配置安装器 | 独立只读查询工具与不覆盖已有目录的Codex复制安装器 |

原版CLI引擎只在原版备份保留。新CLI执行目录读取、条目查询、词语检索和七项词表初筛；设计推荐、图像理解和原创改写由使用技能的模型执行，不将模板拼接冒充生成引擎。

## 原典与历史局限

原典保留历史示例、作者名和平台参数，作为知识资料。实际执行以Codex入口与流程说明为准；旧模型参数不直接沿用，产品事实需用户提供或查证，原典范文不能整段作为原创输出。

没有运行或修改原版构建脚本，没有修改源文件、原Gemini配置或原工作区的 `.agents` 联接。GitHub发布包装增加的README位于载荷外部。
