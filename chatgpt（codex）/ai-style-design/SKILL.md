# 视觉与叙事风格设计（Codex 版）

基于反重力原版语料，提供风格分析、设计系统与原创文案。用户指定的品牌、媒介、流派和事实优先于库中的示例。

## 路由与按需读取

1. 分析已有图片、描述、文案或提示词时，读 [分析流程](references/analyzer.md)。只有文字时，只判断文字可支持的属性；图片必须先实际查看。
2. 创建设计方案或重写时，读 [设计流程](references/designer.md)。未指定流派用模式 A 推荐；已指定用模式 B 锁定；明确要求融合用模式 C。
3. 在 [流派目录](references/catalog.md) 找到 ID，仅阅读相关视觉或叙事参考。每次通常读取一至两个视觉条目，以及有文案需求时的一至两个叙事条目。
4. [叙事质量准则](references/narrative-quality.md) 用于文案和讽刺叙事任务。

全部资源以本 SKILL.md 所在目录为基准解析。无需原项目、Gemini 配置、网络服务或 API 密钥。不要运行反重力安装器或生成脚本。

## 核心判断

- 从具体颜色、物理材质、字阶、对齐、网格和语言节奏说明风格，避免只有风格名称和抽象褒义词。
- 区分观察、推断与建议。图片目测颜色只能是估计 HEX；没有像素或测量依据时不能声称已精确采样。
- 库中的色盘、禁忌和留白比例是特定风格的设计参考。不要把65%留白、12栏网格或60:30:10配色套到所有流派。孟菲斯、赛博等流派的高饱和度和装饰应结合用途判断。
- 流派匹配与同质化诊断是审美启发式判断，不是作者身份鉴定、AI生成检测或统计概率。“严格锁定”表示遵守已选设计约束，不承诺100%历史真实性或生成成功率。
- 保护用户主题、产品事实与已有品牌约束。原典范例只展示技巧，不能整段充当用户的新文案，不编造产品数据、测试结果、获奖或真实引语。
- 编写生图提示词时先给模型通用的自然语言版本。仅在用户指定生成平台且已确认语法时加入平台参数；原典中的旧版模型旗标不作为默认值。
- 若任务要求实际图像、网页或文件，继续使用当前环境适合的生成或编辑工具完成交付。技能资料和CLI不会自行生成图片；只有提示词时如实说明交付类型。

## 可选本地工具

`scripts/style_library.py` 使用 Python 3.10+ 标准库，适合列目录、读结构化条目和做关键词初筛。把命令中的脚本路径替换为本技能实际路径；运行目录任意。

```text
python "<skill-root>/scripts/style_library.py" list --category visual
python "<skill-root>/scripts/style_library.py" show style-bauhaus
python "<skill-root>/scripts/style_library.py" search "茶 包装" --limit 3
python "<skill-root>/scripts/style_library.py" diagnose --text "赋能极致体验，蓝紫霓虹"
```

诊断工具输出原版七项规则命中与归一化指标；阅读上下文后再判断命中是否构成问题。不能把未命中解释为作品优秀。JSON索引 [corpus_index.json](references/corpus_index.json) 适合程序处理，不要默认整份载入上下文。

## 交付

分析给出流派候选、证据、不确定性、问题与改写；设计给出所选流派及理由、色彩和材质、网格和字阶、适用的文案与提示词。按用户需要选择篇幅，具体模板见对应流程。
