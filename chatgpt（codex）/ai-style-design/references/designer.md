# 风格设计与生成调度

## 三种模式

**模式 A：情境推荐。** 根据产品、受众、媒介和情绪给出合适的视觉流派；需要文案时匹配叙事方法。可给少量备选并说明差异，选择后读取相应原典。重要约束缺失时只询问影响交付的信息，其他采用明确的合理假设。

**模式 B：指定流派。** 用户明确指定的流派、品牌色和媒介优先。提取该条目的关键结构、材质、配色和禁忌，说明适用的当代调整。若原典示例与用户对象不同，保留用户对象，不复制示例里的塔楼、人物或产品。只指定叙事流派的任务可只写文案。

**模式 C：明确融合。** 用户要求融合时，分别确定结构骨架、色彩材质与叙事来源，例如“瑞士网格作信息骨架，热带现代主义提供色块与硬光”。说明主次和冲突的解决办法，避免把两套装饰与全部色盘直接相加。没有融合请求时不擅自改成混合风格。

## 可交付内容

根据需求选择相关内容，不强制为短任务生成整本方案：

1. 设计概念：所选流派、用途、受众和判断依据。
2. 视觉参数：HEX及用途、比例、物理材质和光线；原典比例只是起点，调整时说明理由。
3. 排版：画幅、网格、边距、字号层级、字体角色、对齐与留白。网页需要响应式行为；小字和正文确保可读性。
4. 原创文案：主标题、副标题、正文、CTA，篇幅依媒介而定。未提供的性能、价格、时间用占位项或省略。
5. 图像提示词：主题、构图、材质、光线、色盘、排版空间；负向词只排除确实冲突的元素。中文文字需精确时，优先后期排版并明确流程。
6. 若用户要求实际产物，调用环境中适用的生图、网页、文档工具继续完成，并检查输出。只有方案／提示词时不声称已经生成图片或上传外部平台。

收尾时按 [分析流程](analyzer.md) 做一次适用性复核，重点查看主题丢失、材料不合用途、字体不可用和空泛文案。
